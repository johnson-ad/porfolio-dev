🚀 DÉMARRAGE EN 3 ÉTAPES
═══════════════════════════════════════════════════════════════════════════

ÉTAPE 1 : INSTALLER LES DÉPENDANCES
───────────────────────────────────
$ npm install

ÉTAPE 2 : CONFIGURER L'ENVIRONNEMENT
─────────────────────────────────────
Créez un fichier .env avec vos credentials Supabase :

VITE_SUPABASE_URL=votre_url
VITE_SUPABASE_ANON_KEY=votre_cle
VITE_APP_URL=http://localhost:3000

(Voir SUPABASE_SETUP.md pour la configuration complète)

ÉTAPE 3 : LANCER L'APPLICATION
───────────────────────────────
$ npm run dev

Ouvrez http://localhost:3000 🎉

🆘 SUPPORT & AIDE
═══════════════════════════════════════════════════════════════════════════

PROBLÈME : L'application ne démarre pas
SOLUTION : 
  $ rm -rf node_modules package-lock.json
  $ npm install
  $ npm run dev

PROBLÈME : Erreur Supabase
SOLUTION : Vérifiez .env et SUPABASE_SETUP.md

PROBLÈME : Erreur de build
SOLUTION : 
  $ rm -rf node_modules/.vite
  $ npm run dev

• Consultez la documentation (7 guides)
